# Himanshu Overlays

Free live stream overlays for OBS, Streamlabs, vMix and more. No account, no subscription, no watermark.

## Overlays
- **Cricket Scorebug** — live scorecard with runs, wickets, overs, CRR
- **Football Scorebug** — match score with live clock
- **Lower Third** — animated name + title banner
- **Breaking News Ticker** — scrolling headlines
- **Countdown Timer** — "starting soon" screen
- **LIVE Bug** — pulsing live indicator

## How to use in OBS
1. Open the site, pick an overlay, customize it.
2. Copy the **view** link.
3. OBS → Sources → + → Browser → paste URL → 1920x1080 → OK.
4. For live control (scores, clock), use the **control** link and right-click the source → **Interact**.
